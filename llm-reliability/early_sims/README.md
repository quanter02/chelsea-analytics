# 초기 시뮬레이션

프로토타입(`llmrel/`)을 만들기 전, 질문에 답하려고 돌린 가상 데이터 시뮬레이션입니다. 결과 그림은 `figures/`에 있습니다.

| 파일 | 질문 | 핵심 결과 |
|---|---|---|
| `01_personality_pooling.py` | 성격(MBTI 등)을 유형으로 나눌까, 연속 점수로 쓸까 | 연속 점수 통합 모형의 신뢰구간이 약 2.7배 좁음. 텍스트에서 뽑은 점수만 쓰면 효과가 0.12 → 0.044로 축소 |
| `02_forgetting_and_version_change.py` | 데이터가 매주 쌓일 때 무엇이 달라지나 | 선호가 바뀐 뒤 단순 누적은 26주 후에도 17% 어긋남. 측정 도구 교체 시 버전 보정으로 편향 +6.6% → +0.1% |
| `03_update_speed_vs_information.py` | 업데이트를 빨리 돌리면 한계가 줄어드나 | 7배 자주 돌려도 적응 10.9주 그대로. 변화 감지형은 0.9주 |
| `04_llm_cause_breakeven.py` | LLM 원인 분류는 몇 % 정확해야 이득인가 | 경보 시 호출 기준 약 59%. 사건 기록 시 호출이 매주 호출의 1/6 호출로 거의 같은 성능 |

모두 제가 정한 가정에서 나온 숫자입니다. 실제 데이터로 확인한 결과는 `../real_data_demo.py`에 있습니다.
