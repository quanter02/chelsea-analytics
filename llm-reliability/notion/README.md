# 노션 연동

## 지금 바로: 가져오기 패키지
```bash
python notion/build_export.py     # → notion/export/한계효용 신뢰도 엔진.zip
```
노션 왼쪽 사이드바 **설정 → 가져오기 → Markdown & CSV**에서 zip 파일을 선택하면 아래 구조가 만들어집니다.

```
한계효용 신뢰도 엔진            (홈: 전체 흐름, 웹 화면·코드 링크)
├── 설계 원칙
├── 실험 기록      [DB]  이름 · 단계 · 데이터(가상/실제) · 핵심 결과 · 한계 · 코드 · 상태
├── 주장           [DB]  국가 · 지표 · 기간 · 값 · 출처 종류 · 검증 상태 · 결정(채택/보류/제외)
├── 데이터 출처    [DB]  접근 상태(가능/차단/키 필요) · 필요한 것
├── 다음 할 일     [DB]  필요한 것 · 우선순위 · 상태
├── 결과 리포트    (모델 신뢰도, 온라인 갱신, 추출, 실제 데이터 검증 + 그림)
├── 초기 시뮬레이션
└── DB 스키마와 코드 구조
```

가져온 뒤 노션에서 해두면 좋은 것:
- **실험 기록**: `단계`, `데이터`, `상태` 열을 '선택' 속성으로 바꾸고, `단계`별로 묶은 보드 보기를 추가합니다.
- **주장**: `결정`, `검증 상태` 열을 '선택' 속성으로 바꾸고, `결정 = 채택`인 항목만 보이는 필터 보기를 추가합니다.
- **다음 할 일**: `상태`로 묶은 보드 보기를 추가합니다.

## 노션에 만들어진 작업 공간 (2026-10-04)
커넥터로 노션에 직접 만들었습니다. 페이지와 데이터베이스 ID는 `workspace.json`에 있습니다. 다음 동기화 때는 새로 만들지 말고 이 ID로 찾아 갱신합니다.

## 커넥터 연결 후: 직접 동기화
1. https://claude.ai/customize/connectors 에서 Notion을 연결합니다.
2. 새 세션을 엽니다 (커넥터는 세션을 시작할 때 읽힙니다).
3. "llm-reliability/notion/export 내용을 노션에 동기화해줘"라고 요청합니다.

동기화할 때 같은 항목을 중복으로 만들지 않도록, 아래 열을 기준으로 이미 있는 행을 찾아 갱신합니다.

| 데이터베이스 | 기준 열 |
|---|---|
| 실험 기록 | 이름 |
| 주장 | 링크 + 지표 + 기간 |
| 데이터 출처 | 출처 |
| 다음 할 일 | 할 일 |

새 실험이나 주장이 생기면 `build_export.py`의 목록이나 `data_claims/*.csv`에 추가하고 다시 실행합니다.
