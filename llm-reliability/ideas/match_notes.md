# 경기 관찰 노트 (사용자 작성)

경기를 보면서 "시장(배당)이 놓치는 것 같다"는 장면을 적는 곳.
여기 적은 아이디어는 바로 장부에 들어가지 않는다. 아래 순서를 통과해야 한다.

1. 관찰 → 2. 가설 한 줄 → 3. **경기 전에 알 수 있는 정보인가?** (경기 중·후 정보면 탈락)
→ 4. 숫자로 바꾸기 → 5. 아이디어 실험대(`epl_idea.py`) 검증 구간 통과 → 6. 가상 베팅 장부 규칙 v2로 등록

시도한 아이디어 수는 전부 센다. 많이 시험할수록 우연히 통과하는 것도 늘어난다.

## 쓰는 틀 (한 아이디어당 하나)

### 아이디어 이름:
- 날짜 / 경기:
- 본 장면 (무엇을 봤나):
- 가설 (시장이 무엇을 과대·과소평가하나):
- 경기 전에 알 수 있나? (예: 선발 명단, 휴식일, 감독 교체, 날씨 / 아니오: 경기 중 퇴장)
- 숫자로 바꾸면 (어떤 자료, 어떤 계산):
- 어느 쪽으로 미나 (홈승 / 무 / 원정승):
- 자신감 (%):
