# 셈법 데이터로 푸는 SQLD 연습 문제

셈법에서 실제로 쓰는 KOSIS 데이터와 예측 장부로 만든 문제입니다. 문법은 시험 기준인 **Oracle**입니다.

- 풀이는 `my_answers.sql`의 `-- Qnn` 줄 아래에 씁니다.
- 채점: `python practice/grade.py` (특정 문제만: `python practice/grade.py 4 13`)
- 정답 `answers.sql`은 다 풀고 나서 여세요. 채점기는 열지 않아도 결과만 비교합니다.
- 열 이름은 자유이고, **열의 순서와 값**이 맞아야 합니다. 정렬이 적힌 문제는 순서까지 봅니다. 숫자는 소수 넷째 자리까지 비교합니다.

## 테이블

| 테이블 | 내용 | 키 |
|---|---|---|
| `REGION` | 지역 343곳. `parent_code`로 전국 → 시도 → 시군구 → 일반구가 연결됩니다. `region_type`: 전국·시도·시군구·일반구·동읍면부·변동전·기타(국외). `is_analysis = 'Y'`인 229곳이 성비 분석에 쓰는 시군구입니다 | `code` |
| `POPULATION` | 2022~2025년 등록 인구. `sex`는 M/F, `kind`는 total(전체)/unmarried(미혼), `age_band`는 '20-24'~'40-44', 인구는 `pop` | `(yr, code, sex, kind, age_band)` |
| `MARRIAGE_YEAR` | 2005~2025년 지역별 연간 혼인 건수 `cnt` | `(code, yr)` |
| `MARRIAGE_MONTH` | 2005-01~2026-07 시도별 월간 혼인 건수. `ym`은 'YYYYMM' | `(code, ym)` |
| `MIGRATION` | 순이동률. **다른 코드 체계**(`mcode`)라 REGION과 바로 조인되지 않음 (자유 탐색용) | `(yr, mcode, sex, age_band)` |
| `LEDGER` | 예측 장부 500줄. `hash = sha256(prev_hash ‖ body_json)` | `seq` |
| `NOWCAST` | 2026년 시군구 혼인 건수 예측 243곳. `actual_2026`은 2027년 공표 전까지 NULL | `code` |
| `PRACTICE_LOG` | DML·TCL 연습용 빈 테이블 `(id, note)` | `id` |

**미혼 성비**: 같은 연령대에서 미혼 남성 수를 미혼 여성 수로 나눈 값입니다. 특별한 말이 없으면 **2025년, 25~39세**('25-29', '30-34', '35-39')를 기준으로 합니다.

## 1과목: 데이터 모델링 (손으로 풀기)

**M1.** 원본 CSV는 모든 줄에 지역 이름(`name`)이 반복됩니다. 이대로 `(yr, code, sex, kind, age_band, name, pop)` 테이블을 만들면 어떤 이상 현상이 생기나요? 몇 정규형을 위반하나요?

**M2.** `REGION.parent_code → REGION.code`는 어떤 관계인가요? 차수(1:1, 1:N, M:N)와 필수/선택 여부는? `parent_code`가 NULL인 행은 무엇인가요?

**M3.** `POPULATION`의 주식별자는 어떤 종류의 식별자인가요? 대리 식별자 `id`로 바꾸면 무엇을 따로 지켜야 하나요?

**Q03. CASE로 조건부 집계**

열: `ratio`
확인: 노션의 '25~39세 전체 1.33배'와 같아야 합니다.

**Q04. 조인 + 집계 + Top-N**

확인: 1위는 인제군 3.21입니다.

**Q05. PIVOT**

열: 연령대, 미혼 남, 미혼 여, 성비(ROUND 2) · 정렬: 연령대 순

**Q06. ROWNUM Top-N (시험 단골 함정)**
미혼 성비가 가장 **낮은** 분석 대상 시군구 10곳을 **ROWNUM으로** 구하세요.
열: 순번(ROWNUM), 시군구 이름, 성비(ROUND 2) · 정렬: 순번 순
확인: 1위는 마포구 0.89이고, 10곳 모두 서울입니다. `WHERE ROWNUM <= 10 ORDER BY ...`를 한 쿼리에 같이 쓰면 왜 틀리는지 설명할 수 있어야 합니다.

**Q20. TCL — SAVEPOINT (먼저 손으로 예측)**

