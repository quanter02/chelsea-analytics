# 예측 장부

결과가 나오기 **전에** 낸 예측만 여기에 남습니다. 한 줄 = 예측 하나. 추가만 하고 고치지 않습니다.

- `hash` = sha256(앞 줄의 hash + 이 줄 내용). 과거 줄을 하나라도 고치면 그 뒤가 전부 어긋나 `verify`가 잡아냅니다.
- 날짜 증거는 두 겹입니다: 줄 안의 `recorded_at`(UTC)과, 그 줄이 처음 들어간 **git 커밋 시각**(GitHub에 남음).
- 같은 경기 예측을 다시 내면(내용이 바뀐 경우만) 새 줄로 남습니다. 예측을 고친 이력도 공개됩니다. 채점은 경기 시작 전 마지막 줄로 합니다.
- `kind`: `epl` 우리 EPL 예측 · `epl_opta` 비교용 Opta 값(사용자 제공) · `nowcast_2026` 시군구 2026년 혼인 건수 예측

검증

```bash
python -m llmrel.ledger verify     # 정상 254줄 <마지막 hash>
git log --format='%h %cI' -- ledger/predictions.jsonl   # 각 줄이 들어간 시각
```

공개 글·영상에는 마지막 hash 앞 16자리를 같이 적습니다. 나중에 누구든 이 레포에서 같은 hash가 그 날짜 이전 커밋에 있었는지 확인할 수 있습니다.
