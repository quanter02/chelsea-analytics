# 주장(claims) 데이터

기사·영상에서 뽑은 주장을 한 줄에 하나씩 기록합니다. 수치 자체보다 **출처의 종류와 검증 상태**를 함께 남기는 것이 목적입니다.

| 열 | 의미 |
|---|---|
| `source_type` | 공식 발표 / 공식 수치 인용 보도 / 2차 정리 / 일화 / 해석·의견 |
| `verification` | 보도 일치(여러 매체가 같은 수치) / 단일 보도 / 원문 확인 필요 / 불일치 / 확인 불가 |
| `decision` | 채택 / 보류 / 제외 (한계효용 기준: 관련성 · 새로움 · 검증 경로) |

## kr_jp_marriage_2026.csv

2026년 10월 4일 웹 검색으로 모은 한·일 결혼·출생 관련 주장 19건입니다.
- 일본 후생노동성, e-Stat 원문은 수집 환경에서 접근이 막혀 있었습니다. 그래서 일본 수치는 여러 매체가 같은 값을 보도한 경우에만 채택했습니다.
- 원문을 직접 열어 대조하기 전까지 `보도 일치`는 `원문 확인`과 같지 않습니다.
