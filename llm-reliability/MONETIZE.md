## 지금까지 만든 것의 공통 구조
**개인 기록 → AI 채점(기준표 + 틀린 유형 태그) → 약점 진단 → 맞춤 문제 자동 생성 → 간격 반복 → 재측정**
같은 루프를 토익, 일본어 작문, 대화 습관, 코테에 적용했다. 팔 수 있는 건 개별 콘텐츠보다 이 루프다.

## 검증 방법 (토익 후, 비용 0원)
1. 후보 1 또는 2 하나만 고른다.
2. 지인·학교 커뮤니티 5~10명에게 2주 무료 사용 → 주 3회 이상 쓰는 사람 비율, 2주 뒤 "계속 쓰고 싶다" 비율 측정.
3. 기준: 2주 유지율 40% 이상 + 3명 이상이 유료(월 5천~1만 원) 의향 → 다음 단계. 아니면 접기.
4. 비용 확인: 채점 1회당 API 비용 × 하루 사용 횟수로 1인 월 비용 계산 후 가격 결정.
