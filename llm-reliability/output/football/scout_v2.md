# 셈법 스카우트 v2: 가격(시장가치)을 붙인 베테랑 검증

자료: understat 선수 시즌 (5대 리그 2017/18~2025/26) + transfermarkt-datasets (생년월일·시장가치·계약, 2026-07-06 스냅샷).
1500분+ 선수의 트랜스퍼마크트 연결률 80%. 가설·규칙은 실행 전에 장부 고정.
'싸다' = 같은 시즌·포지션 1500분+ 선수 중 시장가치 하위 절반 (v0·v1의 '하위 절반 팀' 대리 대신 가격 자체).
'좋은 시즌' = 다음 시즌 1500분+ 이고 역할 지표 상위 절반.

## 가설 판정 (선발 2017/18~2024/25)
| 가설 | 결과 | 판정 |
|---|---|---|
| H1 같은 가격대에서 29~31세가 25~28세보다 좋은 시즌 비율이 높다 (시장이 나이를 과하게 깎음, 자신감 50%) | 차이 +8.9%p (95% +6.0% ~ +11.7%), 베테랑 1324 / 25~28세 2626 | 맞음 |
| H2 싸고 역할 좋은 베테랑이 싸고 역할 평범한 베테랑보다 다음 시즌 1500분+ 비율이 높다 (자신감 60%) | 55% (n=102) vs 49% (n=805), 차이 +5.5%p (95% -5.1% ~ +15.9%) | 불확실 |
