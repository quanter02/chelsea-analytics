# EPL 모델 vs 시장 배당

시장 확률 = 마감 직전 배당(피나클 1730경기, 평균 230경기)에서 북메이커 마진을 뺀 값. 같은 경기 1960개 비교.
RPS 낮을수록 좋음. 차이 = 시장 − 우리 (**음수면 시장이 더 잘 맞힘**). 95% 범위는 경기 단위 부트스트랩.

## 결론
- **시장이 더 잘 맞힌다.** 검증 구간(1,140경기)에서 확실히 지고(범위가 0 아래), 시험 구간(760경기)에서도 차이 −0.004.
- 리그 평균 기준선(0.2317)에서 시장(0.2006)까지 거리 중 **88%**를 우리 모델이 따라감.
- 시장과 섞어 보면 검증 구간 최적 비중이 우리 모델 0% → 우리 모델은 시장이 이미 아는 것 외에 더하는 정보가 없다.
- 두 확률의 상관 0.91, 홈승 확률 평균 차이 0.062: 대체로 비슷한 판단을 하되 시장이 조금 더 정확.
- 이번 시즌 60경기는 범위가 넓어 판정 불가.
