# 소유와 공개 범위

## 지금 상태 (2026-10-05)

- 레포 `quanter02/chelsea-analytics`는 **공개**이고, 루트 `LICENSE`가 **MIT**입니다.
- 그래서 지금까지 푸시한 `llm-reliability/` 코드와 가공 데이터는 누구나 복사·수정·상업적으로 쓸 수 있습니다. 이미 공개된 버전의 MIT 허락은 되돌릴 수 없습니다.
- 앞으로의 버전은 저작권자가 조건을 바꿀 수 있습니다 (비공개 전환, 다른 라이선스).

## 무엇이 진짜 자산인가

| 자산 | 복제 난이도 | 지키는 방법 |
|---|---|---|
| 예측 장부·채점 기록 (`ledger/`) | 매우 어려움 — 시간이 필요 | 공개해도 됨. 해시 체인과 git 커밋 시각이 "먼저 냈다"는 증거라 공개할수록 가치가 커짐 |
| 규칙 체계 (확실할 때만 채택, 트로피 기준, 스쿼드 운영) | 중간 | 이름을 붙여 브랜드로. 원리는 공개해도 운영 실적은 복제 불가 |
| 엔진 코드 (튜닝, 나우캐스트, 스쿼드, 팩트체커) | 쉬움 | 앞으로의 개선판은 비공개 레포에서 |
| 가공 데이터·해석·콘텐츠 | 중간 | 사람의 기획·해석·편집을 분명히 넣기 |

## 권장 구조 (결정 필요)

| 레포 | 공개 | 담을 것 |
|---|---|---|
| 지금 레포 (공개) | 공개 | 장부(`ledger/`), 성적표·트로피 진열장 보고서, 방법론 문서, 데모 |
| 새 엔진 레포 | **비공개** | `llmrel/`의 개선판, 팩트체커 엔진, 콘텐츠 자동화 루틴 |

전환 순서
1. 새 비공개 레포를 만든다 (GitHub에서 직접, 또는 요청 시 세션에서).
2. 다음 개선부터 엔진 변경은 비공개 레포에만 넣는다.
3. 공개 레포의 루트 LICENSE는 그대로 두되(과거 버전은 어차피 MIT), `llm-reliability/` 안에 별도 라이선스를 둘지 결정한다.
4. 레포 전체를 비공개로 돌리면 노션 이미지(GitHub raw 주소)가 깨지므로, 이미지는 먼저 다른 곳으로 옮긴다.

이 문서는 결정을 돕는 안이며, 라이선스·공개 범위 변경은 저장소 주인이 정합니다.
