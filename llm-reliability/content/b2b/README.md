# 지자체 리포트 243곳: 영업 우선순위

모든 시군구에 같은 틀의 리포트를 만들었습니다(`report_<코드>.html`). 2026년 예측은 모두 '1~6월 신호' 하나로 통일했습니다.

## 왜 방식을 하나로 통일했나

- 시군구마다 과거(2008~2018)에 가장 좋았던 방식을 골라 쓰면, 이후(2019~2025) 평균 오차 9.0%. 모든 곳에 1~6월 신호를 쓰면 8.6% — **하나로 통일한 쪽이 더 정확**했습니다. 지역별 선택은 과거 우연에 맞춰진 것.
- 과거 구간 성적과 이후 성적의 상관은 0.18로 약했습니다. 과거에 1~6월 신호가 졌던 42곳 중에서도 83%는 이후 구간에서 이겼습니다.
- 플랜 A 원칙(단순하지만 강력한 하나)과 같은 결론입니다.
