# 시군구 월별 혼인 건수 (1997.01 ~ 2025.12)

- 출처: 통계청 KOSIS, 인구동향조사 `DT_1B83A35` (시도/시군구/월별 혼인). 2026-10-08 KOSIS OpenAPI로 내려받음.
- 열: `code` (KOSIS 지역 코드), `name`, `ym` (YYYYMM), `marriages` (혼인 건수)
- 지역 코드: 2자리 = 전국·시도, 5자리 = 시군구 (끝자리가 0이 아니면 일반구).
  `(변동전)`이 붙은 코드는 행정구역 개편 전 계열입니다(예: 창원 2010 통합, 청주 2014 통합).
- 시군구 월별 확정치는 다음 해 초에 한 번에 공표됩니다. 매달 나오는 월별 인구동향(`DT_1B8000G`)은 시도 단위까지만 있습니다.
- 공공데이터로 상업 이용이 가능합니다. 다만 출처("통계청 KOSIS"와 표 번호)를 표기하고 가공했음을 밝혀야 합니다.
