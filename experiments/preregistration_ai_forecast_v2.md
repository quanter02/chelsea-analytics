## 판정 (미리 정함, 최종 = 2027년 3월 자료 공표 뒤, 대략 2027년 5월)
- **H1 AI 우위:** 전체 문항에서 개선 = B1 브라이어 − AI 브라이어. 지역·주제 단위 부트스트랩 90% 구간 하한 > 0 → **"AI 우위 확인"**, 개선 > 0이지만 구간이 0 포함 → "방향만 맞음", 개선 ≤ 0 → "AI 우위 확인 안 됨".
- **H2 보정:** AI의 ECE(10구간) ≤ 0.05 → "보정 양호", 아니면 "보정 미흡".
- 보조(결정에 안 씀): 주제별 브라이어, llm-reliability 프로파일(기권 0.4~0.6, 정답, 확신 오답 = 0.2 이하·0.8 이상인데 틀림), 1차 손 조정과 겹치는 순이동 10~12월 비교.
- 중간 결과는 공표된 달까지 매달 '중간'으로만 기록.

## 상품으로서의 의미
- H1·H2가 모두 통과하면: "AI 예측을 미리 고정·공개하고 채점한 기록"을 보여 주는 첫 신뢰 계층 리포트(어떤 주제에서 AI를 믿고, 어디서 통계 기준선으로 돌아갈지 = 라우팅).
- 통과하지 못해도: "AI가 공식 통계 단기 예측에서 기준선을 못 이긴다"는 사전 등록 기록 자체가 공개할 결과입니다.
