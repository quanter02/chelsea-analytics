# 사전 등록: 미분양 월간 경보로 통일 점진 규칙 2차 vs 5차 검증

- 작성: 2026-10-09. **이 문서는 미분양 값(수치)을 내려받기 전에 커밋합니다.** 확인한 것은 표 구조(메타데이터)뿐입니다.
- 자료: 국토교통부(KOSIS orgId 116) `DT_MLTM_2082` 시·군·구별 미분양현황. 월별, 2000.12 ~ 2026.08. 항목 1개(미분양 호수, **재고**). 분류: 구분(시도 19) × 시군구(219).

## 입력 (주제의 사실 — 재고 자료에 맞춘 정의)
- 단위: (시도, 시군구) × 연도 Y. 시군구 이름이 '계'인 행은 제외.
- L0 = Y-1년 12월 미분양 호수, L1..L12 = Y년 1~12월.
- 예측(플랜 A, 모든 지역 같은 방식): **작년 12월 값이 그대로 유지** (월별 변화 예측 = 0).
- 증거: 월별 변화 e_m = L_m − L_(m−1). 누적 S_n = L_n − L0.
- 규모 s = L0 + 50 (재고가 0인 지역의 나눗셈 방지).
- 분산: var_m = φ · s, φ = 보정 기간(아래 평가 대상)의 평균(e_m² / s).
- 이탈률: dev = (L12 − L0) / s.
- 평가 대상: L0 ≥ 100호.
- 이탈 해: |dev| ≥ 보정 기간 |dev| 분포의 80% 분위수. 정상 해: < 50% 분위수(CLEAR). 사이는 제외.
- 규모 구간(L0): 100~500, 500~2,000, 2,000 이상.
- 기간: 보정 2010~2016 (예측 연도), 채점 2017~2025, 실시간 2026년 1~8월.
- 월이 하나라도 빠진 단위-연도는 채점에서 제외(실시간은 공표된 달까지만).

## 비교하는 규칙
공통: 정규 혼합 신뢰 시퀀스 반폭 hw = √((V+V0)·(log(1+V/V0) + 2·log(1/α′))), V = 누적 분산, V0 = 6개월치 분산(6·φ·s), α′ = α/2 (증가·감소 두 방향).
m 후보(단위 없는 형태): CLEAR × [0, 0.2, 0.4, 0.6, 1.0, 1.5, 2.0, 2.5, 3.0].

| | 2차 (현재 채택) | 5차 (후보) |
|---|---|---|
| 판정 | (S − hw)/s > m 이면 증가 경보 (감소는 대칭) | (S − hw)/s > 0 **그리고** S/s > m 이면 증가 경보 (감소는 대칭) |
| α 후보 | 0.9, 0.7, 0.5, 0.3, 0.2, 0.1, 0.05, 0.01 | 0.99, 0.95, 0.9, 0.7, 0.5, 0.3, 0.2, 0.1, 0.05, 0.01 |
| 고르는 순서 | 가장 작은 m부터 → 그 안에서 가장 민감한 α부터 | 가장 민감한 α부터 → 그 안에서 가장 작은 m부터 |
| 보정 기준 | 보정 기간 **전체** 잘못된 경보 ≤ 10% | 보정 기간 **모든 규모 구간에서 각각** 잘못된 경보 ≤ 10% |

참고용(결정에 쓰지 않음): 단순 규칙 "누적 추정치 |S/s| ≥ x", x는 같은 m 후보에서 보정 기간 전체 잘못된 경보 ≤ 10%인 가장 작은 값.

## 통과 조건과 결정 규칙 (채점 기간 2017~2025)
- 규칙이 **통과**하려면: 전체 잘못된 경보 ≤ 10% **그리고** 모든 규모 구간에서 잘못된 경보 ≤ 10%.
- 결정:
  1. 5차만 통과 → 5차 채택
  2. 둘 다 통과 → 5차 감지율이 2차보다 5%p 넘게 낮지 않으면 5차 채택, 아니면 2차 유지
  3. 2차만 통과 → 2차 유지
  4. 둘 다 실패 → 둘 다 채택하지 않음(현재 2차를 '미분양에서는 미검증'으로 표시)
- 보조 정보(결정에 쓰지 않음, 이미 본 자료): 5차를 혼인·청년 순이동·EPL에 적용한 결과.
