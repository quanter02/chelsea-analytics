# 메일리 정리 3가지 (복사해서 붙여 넣기)

## 1. 1호 글 미리보기 고치기 (약 3분)
1. 메일리 관리 화면 → 뉴스레터 관리 → 1호 오른쪽 ⋮ → 수정
2. 본문 맨 위에서 아래 줄들이 보이면 **지웁니다** (웹 버전 머리 부분이 같이 들어간 것):
   - `통계청 KOSIS DT_1B26001 기반` / `2026년 10월 · 8월 공표분`
   - `지역 인구 이동 월간 경보 제1호` (제목은 위에 이미 있음)
   - `경보 목록 지문 10e84fd4561e0a64` (지문은 본문 아래 '믿을 수 있나' 부분에 이미 있음)
3. 본문 첫 문장이 아래로 시작하면 됩니다:
   > 2026년 8월까지 공표된 통계청 자료로, 예측보다 확실히 벗어난 시군구만 골랐습니다.
4. 글 설정에 '요약'·'미리보기'·'부제목' 칸이 있으면 아래를 넣습니다:

```
농어촌 기본소득 시범 군, 사람이 정말 늘었나. 2026년 8월까지 인구가 예측에서 확실히 벗어난 시군구 44곳.
```
5. 저장할 때 **발송 대상은 '이메일 미발송'** 그대로 둡니다.

## 2. '응원하기' 버튼 끄기 (약 1분)
- 왼쪽 메뉴 '수익/정산' → 응원하기(후원) 설정에서 끄기.
- 거기 없으면 '사이트 설정' → 프로필(또는 버튼) 설정에서 '응원하기' 끄기.
- 이유: 사업자 등록(2027년 3월) 전에는 돈을 받는 기능을 쓰지 않는 편이 깔끔합니다.

## 3. '메일러 소개' 탭 채우기 (약 2분)
메일리 페이지의 '메일러 소개' 탭 → 편집(또는 '사이트 설정' → 소개). 아래를 통째로 붙여 넣습니다.

```
매달 국내인구이동통계가 나오면, 전국 시군구 중 순이동이 예측에서 확실히 벗어난 곳만 알려 드립니다. 군 지역은 따로 정리합니다.

· 판정 기준은 자료를 보기 전에 공개해 두고 매달 바꾸지 않습니다.
· 낸 경보는 모두 기록해 두고, 연말 확정치가 나오면 맞았는지 공개합니다.
· 정책 발표(예: 농어촌 기본소득 시범사업) 전후의 인구 이동도 같은 방식으로 판정합니다. 결과가 기대와 달라도 그대로 공개합니다.
· 원인은 판단하지 않습니다. 예측 대비 차이만 보여 드립니다.

이런 분께: 지자체 인구·청년 정책 담당자, 지역 기자, 지방의회 보좌진, 인구 정책 연구자
무료 · 월 1회 (국내인구이동통계 공표 뒤)

얼마나 믿을 수 있나: 2018~2025년 채점에서 크게 벗어난 해의 72%를 잡았고, 평범한 해에 잘못 울린 비율은 5%였습니다.
자료: 통계청 KOSIS 국내인구이동통계(공공데이터, 가공함)

개인정보 안내: 구독 신청 시 받는 정보는 이메일 주소뿐이며, 뉴스레터 발송에만 씁니다. 구독을 취소하면 지체 없이 삭제합니다.
```
